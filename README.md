# MUSIC-BEAT-FINAL

Este proyecto es la entrega final de la clase de Multimedia y consiste en una página web interactiva centrada en la batería, un instrumento clave en la música marca eñ beat de las cnaciones. La propuesta busca que cualquier persona, tenga o no conocimientos previos, pueda acercarse a este instrumento de una forma sencilla y entretenida. A través de la página, el usuario puede explorar datos curiosos, conocer las partes básicas de la batería y entender mejor cómo funciona dentro de distintos contextos musicales.

Además, el sitio incluye elementos visuales y recursos interactivos que hacen la experiencia más dinámica y agradable, fomentando  la exploración. La interfaz está diseñada para ser intuitiva y atractiva, permitiendo una navegación fluida que invite a descubrir cada sección sin dificultad. El proyecto busca despertar el interés por la batería y generar una conexión más cercana con este instrumento a todos los usuarios.
